# Bài Kiểm Tra Đầu Vào — Web Developer (Next.js / React)

Dự án Web App quản trị nội bộ bao gồm các trang đăng ký, đăng nhập và quản lý danh sách sản phẩm theo trạng thái tồn kho, tích hợp API thật.

## 🛠 Tech Stack
- **Framework**: Next.js (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Authentication**: JWT Token (Stored in Cookie & LocalStorage)
